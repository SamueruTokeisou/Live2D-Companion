# 玩法与灵感池

调研日期：2026-11-22。外部项目用于了解设计方向；以下“本项目构想”尚未实现，不代表对方项目承诺，也不是已经收集的用户反馈。

## 从现有项目学什么

| 来源 | 已公开的方向 | 对本项目的启发 |
| --- | --- | --- |
| [AIRI](https://github.com/moeru-ai/airi) | 自托管虚拟伙伴、实时语音、游戏与模块化扩展 | 长期可以按场景加载能力；第一步先把接口分清楚 |

| [DeepFish](https://github.com/Rockau/DeepFish-desktop-pet) | 桌宠与 Agent 状态表达 | 同一事件可通过姿势、表情和短字幕表达，不必每次请求大模型 |

## 我们自己的构想

### 第一批：便宜、可离线、很快能玩起来

1. **番茄钟搭子**：开始专注时坐好，结束后伸懒腰；全屏或免打扰时不弹气泡。失败不责备用户。
2. **性格旋钮**：活泼 / 安静、动作幅度、主动说话频率独立可调；性格首先由行为控制，不是只换提示词。
3. **动作积木**：把“看向左边 → 举手 → 脸红 → 说一句话”存成配方，预览后再加入随机池。
4. **互动记忆的小版本**：只记用户明确设置的称呼、偏好和开关，提供查看、修改和清空；先不用向量数据库。
5. **不打扰模式**：会议、游戏、工作时自动或手动收敛，结束后再回应，宁可少说一句。

### 第二批：有用的陪伴

6. **日语陪练**：按“点餐、问路、表达想法”等意图练短对话；可显示假名、中文释义、跟读和角色表演。先文字与系统声音，之后再选日语 TTS。
7. **音乐伙伴**：用户允许后只读播放器公开状态，跟节奏轻晃或评价用户主动分享的歌曲；不同于常驻录音。
8. **桌面小剧场**：用户选择情境，播放自己写的对话和动作；把表演配方分享出去，接收方使用自己的模型。
9. **学习成长册**：记录自己学会的参数、完成的绑定练习，角色见证制作过程；成长属于用户，不靠连续登录惩罚。
10. **直播小助手**：倒计时、欢迎语、OBS 可用的干净舞台；公开展示先处理角色与声音授权。

### 第三批：有技术挑战的方向

11. **角色能力体检**：自动列出可用眼睛、嘴、转头、物理输入；用户拖滑条即可建立参数映射，缺能力能解释原因。
12. **会话表演导演**：把文本或语音片段拆成情绪与动作计划；嘴型、手势和字幕共用时钟，用户打断时一起停止。
13. **本地事件总线**：计时器、播放器、聊天、模型行为通过类型明确的事件连接；插件可以替换声音或动作，而无需改核心。
14. **双角色互动**：一个窗口两个角色或不同窗口轮流说话。先做手写剧本，等单角色稳定后才考虑多 AI。
15. **角色随身包**：只导出角色能力映射、动作配方与偏好；模型和私密对话留在用户电脑。

## 站在不同使用者角度

下面是假设的用户需求，用于设计讨论，尚未做真实访谈。

| 使用者 | 最可能在意什么 | 产品回应 |
| --- | --- | --- |
| 零基础爱好者 | 不懂文件、怕装坏、希望马上看到角色 | 中文引导、导入体检、原件不动、能恢复 |
| 自己画模型的人 | 换角色后眼嘴反了、动作套不上 | 参数校准、范围与方向映射、预览 |
| 低配电脑用户 | 风扇、内存、耗电、挡鼠标 | 性能档、隐藏停帧、免打扰、轮廓穿透 |
| 动作创作者 | 不会编程但想做小演出 | 积木配方、时间轴、配置分享 |
| 开发者 | 不想为每个功能改核心 | 稳定接口、事件类型、示例插件与测试 |

## 第一轮我最想选的三个玩法

**番茄钟搭子 + 性格旋钮 + 动作积木。** 它们不依赖付费 AI，能让现在的桌宠很快有辨识度，也能直接检验角色行为系统是否好用。

日语陪练是很值得长期做的特色，但应等参数适配和声音链稳定后推进。AI 自动看屏幕、控制电脑、多角色自主行动暂时放后面，避免过早扩大维护范围。

## 如何挑选想法

每个新想法先回答：给谁用？一次具体使用过程是什么？模型现有绑定够不够？离线能否降级？会不会打扰用户？怎样证明它可用？

先用最小演示验证好玩，再决定是否进入正式版本。Ideas 不是承诺清单。
