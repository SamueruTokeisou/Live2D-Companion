外观

设置窗口与动作编辑器共用这一套主题；「跟随系统」跟随 Windows 的浅色/深色模式。

窗口

上下留白
角色大小：把鼠标放在头 / 胸 / 腰 / 胯 / 裙上，按住中键滚轮缩放（以光标为中心，窗口跟着角色走）；也可打开「窗口边框」拖边/角缩放。
中键或右键按住拖角色搬窗口（左键留给互动：点/摸/捏）；空地上右键点一下 → 前倾开关。

性能

默认 30 帧；隐藏到托盘时停止渲染。角色较复杂时可选择省资源档。

动作速度
频率只决定「多久换一段动作」；动作速度决定「动作播多快」。上限 1.0 = 预设速度（模型自带动作的节奏），手和裙子的贴图切换不跟着变速。
常驻换重心 + 每隔几秒来一段小动作（伸懒腰 / 东张西望 / 打瞌睡 / 理头发…），偶尔配一句小台词
「随机小表情」是待机时自己冒出来的笑/吐舌头/单眼眨眼（9–19 秒一次）。觉得「脸怎么自己变了」就关掉它 —— 关掉只影响待机，互动和动作表情照常。

性能（改完需重启舞台）

原生 Core 把每帧的顶点求值从约 8.2ms 降到约 1.7ms，逐顶点结果与官方 WASM 版完全一致；pixi7 分支绘制更快。两者都开是目前最快的组合（实测单帧约 12.7ms / 79fps）。
改完上面的两项后点这里（或托盘菜单「重启引擎」），不用退出整个应用。

模型

发布包不带模型：选你自己拥有的 .model3.json 即可；模型版权归原作者，禁止二次分发

动作与发布

补丁只含姿势/台词/反应/热区，不含模型本体；发布时发这个文件，下载者用自己的原模型加载

窗口行为

穿透时角色区不可点，舞台里会浮出「恢复鼠标」按钮；也可按 Ctrl+Alt+L 找回，Ctrl+Alt+Q 退出

更新

启动 8 秒后查一次仓库的最新版本；有新版本只在气泡里说一句，不会自动下载。
