# 出问题了怎么办：导出故障报告

桌宠出问题时，**不用描述现象**。点一下导出，把文件丢给你的 AI 就行——
报告是给机器读的，结构固定、带环境和时间线。

## 怎么导出

- **托盘图标右键 → 「导出故障报告…」**（推荐，穿透模式下也能点）
- 或者在控制台里：`Live2DStage.exportDiagnostic()`
- 导出后会弹出完整路径，并自动在资源管理器里定位到该文件

文件位置：`%APPDATA%\live2d-stage\故障报告-<时间>.md`

## 报告里有什么

| 段 | 内容 | 为什么需要 |
|---|---|---|
| 基本信息 | 版本 / Electron / Chrome / Node / 系统 / 屏幕与刷新率 / 引擎 / 窗口 bounds / 启动参数 | 一半的问题靠环境就能定位（驱动、刷新率、引擎分支） |
| 设置 | 当前 `settings.json`（已隐藏密钥） | 复现「只有某种设置下才出问题」 |
| 故障记录 | 最近 200 条故障事件，带毫秒级时间戳 | 看时间线：崩溃前发生了什么 |
| 主进程日志 | `main.log` 尾部 120 行 | 启动流程、模型加载、贴图压缩卡在哪一步 |
| 自查顺序 | 三条最短路径 | 给 AI 的提示词也给自己看 |

同时保留机器可读的原始流水：`%APPDATA%\live2d-stage\logs\faults.jsonl`（一行一条 JSON）。

## 故障事件都记什么

| kind | 含义 | 常见原因 |
|---|---|---|
| `renderer:error` | 渲染层未捕获异常 | 扩展脚本写错、模型参数不存在 |
| `renderer:unhandled-rejection` | 未处理的 Promise 失败 | 网络/文件加载失败没 catch |
| `console:error` / `console:warn` | 控制台错误与告警（含扩展加载失败、口型 provider 出错） | 扩展路径写错、TTS 返回格式不对 |
| `renderer:crash` | 渲染进程崩溃（含退出码、重启次数） | 显卡驱动、显存不足、模型异常 |
| `webgl:context-lost` | WebGL 上下文丢失（含第几次） | 合盖唤醒、驱动重置；正常会自动重建 |
| `frame:stall` | 单帧超过 120ms | 大贴图解码、扩展里做了重活 |
| `window:load-failed` / `window:preload-failed` | 页面/预加载失败 | 打包缺文件、沙箱配置 |
| `window:unresponsive` | 窗口无响应 | 主线程被同步操作卡住 |
| `main:uncaught` / `main:unhandled-rejection` | 主进程异常 | 路径/权限问题 |

## 隐私

导出时自动处理，**不会**把密钥和台词发出去：

- 用户目录被替换成 `<用户目录>`（避免泄露用户名）；
- `sk-…` 形式的密钥 → `<已隐藏密钥>`；
- 设置里的 `token` → `<已隐藏>`；
- **不记录**气泡台词、聊天内容、你的输入。

## 直接喂给 AI 的提示词

```
这是我 Windows 桌面 Live2D 桌宠的故障报告（见下）。请逐段看：
1) 基本信息里有没有明显不匹配（引擎、显卡、屏幕刷新率）；
2) 故障记录按时间排，找出崩溃/上下文丢失前后的事件；
3) 主进程日志里定位最后一步成功的操作和它之后的报错。
然后给出：最可能的原因排序、需要我补充的信息、可执行的下一步（含具体命令或设置项）。
```

## 常见签名与对策

| 报告里看到 | 先试这个 |
|---|---|
| `renderer:crash` + `exitCode -1`，反复出现 | 设置里换回 `pixi7` 引擎；或托盘「重启引擎」；仍崩则关硬件加速（`兼容模式.cmd`） |
| `webgl:context-lost` 反复 >2 次 | 更新显卡驱动；报告里会带 `reloads` 次数 |
| `window:load-failed` | 打包缺文件 / 被杀软删了，重装 |
| `console:warn` 里有 `[ext] 加载失败` | 扩展路径写错（应以 `/extensions/` 开头）或文件语法错 |
| `frame:stall` 密集 | 有扩展在每帧做重活；或贴图没压缩（看日志里有没有「贴图压缩」） |
| 只有 `diagnostic-exported` | 没记录到故障事件：问题可能是「表现不对但不报错」，在报告里补一句你的现象再发 |
